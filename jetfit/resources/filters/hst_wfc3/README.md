# HST/WFC3 response provenance

These are frozen total-system throughput curves from the Spanish Virtual
Observatory Filter Profile Service, retrieved 2026-09-13:

- `HST/WFC3_UVIS2.F775W`
- `HST/WFC3_IR.F125W`

The instrument assignment is supported by Zhu et al. (2023), who identify the
two GRB 220101A observations as HST/WFC3 F775W and F125W. The VOTables retain
their SVO metadata and original tabulation. WFC3 throughputs include the full
optical train and detector response, so no additional mirror, filter, or QE
curve is multiplied into them.
